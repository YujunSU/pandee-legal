# Pandee website

This folder is a complete static website for GitHub Pages. Upload the **contents
of this folder** without changing the relative file structure.

## Included pages

- `index.html` — product home page
- `privacy.html` — App Store privacy-policy URL
- `terms.html` — Terms of Use URL for the app and paywall
- `support.html` — App Store support URL
- `styles.css` — shared responsive styling
- `assets/` — Pandee app icon and mascot artwork

## Publish with GitHub Pages

1. Create a public GitHub repository, for example `pandee-site`.
2. Upload every file and the `assets` folder from this directory to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub to show the live site URL.

If your GitHub username is `YOUR_NAME` and the repository is `pandee-site`, the URLs will be:

- Home: `https://YOUR_NAME.github.io/pandee-site/`
- Privacy Policy: `https://YOUR_NAME.github.io/pandee-site/privacy.html`
- Terms of Use: `https://YOUR_NAME.github.io/pandee-site/terms.html`
- Support: `https://YOUR_NAME.github.io/pandee-site/support.html`

Use the Privacy Policy and Terms of Use URLs in the Pandee paywall. Use the Privacy Policy and Support URLs in App Store Connect.
